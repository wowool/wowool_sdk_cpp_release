# Wowool SDK Engine

The Wowool SDK is a self-hosted (on-premise) library that brings Wowool’s NLP capabilities directly into your own infrastructure. Unlike the cloud-based Wowool Portal API, the SDK allows organizations to process text locally—ensuring full control over data privacy, latency, and compliance.
The wowool tir sdk


This repository hosts the SDK's C++ core engine libraries. See the [Releases](https://github.com/wowool/wowool_sdk_cpp_release/releases).
